# LGP-for-RL
A simple Linear Genetic Programming system for Reinforcement Learning tasks

To run the system, run the file LGP_for_RL.py
All parameter changes can be made in the "if \_\_name__ == \_\_main__" function either when initializing the Python classes or when calling the functions.

Package versions:
numpy 1.26.4
matplotlib 3.8.0
gymnasium 1.2.3
